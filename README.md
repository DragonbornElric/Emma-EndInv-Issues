# Emma's Endless Inventory — support

This is the public issue tracker for **Emma's Endless Inventory**, including the
Fabric and NeoForge mods and the Folia/Paper server plugin. Development source
is maintained separately in a private repository.

- [Report a bug or request a feature](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues/new/choose)
- [Browse open reports](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues)
- [Browse all reports, including resolved issues](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues?q=is%3Aissue)
- [Download the client mods on CurseForge](https://www.curseforge.com/minecraft/mc-mods/emmas-endless-inventory)
- [Download the server plugin on CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/emmas-endless-inventory-plugin)

Please search existing reports before opening a new one. For a bug, include the
mod version, Minecraft version, loader, server type, reproduction steps, other
mods or plugins involved, and relevant logs or screenshots. Feature requests
and questions can use a blank issue.

The tracker accepts reports from anyone with a GitHub account. No access to the
private source repository is needed. Reports cover this Emma fork; please do
not send its problems to the original Endless Inventory project's maintainer.

Existing open and resolved reports are retained here. GitHub releases in the
development repository require source-repository access; public downloads
remain on CurseForge.
