# Dimensional Workshop 2 — support & documentation

This is the public issue tracker and documentation page for **Dimensional Workshop 2** (Storage & Crafting; formerly *Emma's Endless Inventory*), including the Fabric and NeoForge mods and the Folia/Paper server plugin. Development source is maintained separately in a private repository.

- [Report a bug or request a feature](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues/new/choose)
- [Browse open reports](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues)
- [Browse all reports, including resolved issues](https://github.com/DragonbornElric/Emma-EndInv-Issues/issues?q=is%3Aissue)
- [Download the client/server mods on CurseForge](https://www.curseforge.com/minecraft/mc-mods/dimensional-workshop-2)
- [Download the Folia/Paper server plugin on CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/dimensional-workshop-2)

Please search existing reports before opening a new one. For a bug, include the mod version, Minecraft version, loader, server type, reproduction steps, other mods or plugins involved, and relevant logs or screenshots. Feature requests and questions can use a blank issue.

The tracker accepts reports from anyone with a GitHub account. No access to the private source repository is needed. Please do not send Dimensional Workshop 2 reports to the original Endless Inventory project's maintainer.
